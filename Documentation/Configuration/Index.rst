=============
Configuration
=============

The module is configured per page. The defaults are defined in
:file:`Configuration/Module/Settings.php` of the extension and can be overwritten in
the page TSconfig of the page which is currently selected in the module, using the
path :file:`tx_newsbunny.module`.
